# 实验四：实现智能图像分类APP——基于TensorFlow Lite的花卉识别应用

## 一、实验目的

1. 掌握TensorFlow Lite在Android平台上的集成与使用方法；
2. 学习如何使用CameraX库实现相机预览和实时图像分析；
3. 理解Android Jetpack中ViewModel与LiveData组件的应用；
4. 掌握将预训练TensorFlow Lite模型导入Android项目并进行图像分类的开发流程。

------

### 3.2 TensorFlow Lite模型导入

TensorFlow Lite是TensorFlow针对移动和嵌入式设备的轻量级解决方案，能够在设备端高效运行机器学习模型，无需与服务器交互。本实验使用预训练的`FlowerModel.tflite`花卉分类模型，该模型基于**EfficientNet-Lite0**架构，输入224×224像素的RGB图像，输出5个类别的概率分布。

导入步骤如下：

1. 在项目资源管理器中选择`start`模块；
2. 右键点击模块，选择 `File → New → Other → TensorFlow Lite Model`；
3. 选择`finish`模块下`ml`文件夹中的`FlowerModel.tflite`作为模型文件；
4. 点击Finish完成导入，系统会自动下载依赖并将依赖项添加至`build.gradle`文件。

成功导入后，可以在Android Studio中直接查看模型的详细信息，包括名称、描述、输入输出张量规格等。如下图所示：

## 四、关键技术解析

### 4.1 CameraX相机库

CameraX是Android Jetpack的相机库组件，极大简化了相机功能的开发。本实验主要使用了两个核心用例：

| 用例            | 功能             | 本实验中的应用                                |
| :-------------- | :--------------- | :-------------------------------------------- |
| `Preview`       | 提供相机预览画面 | 在`viewFinder`上实时显示摄像头取景            |
| `ImageAnalysis` | 获取图像帧供分析 | 将每一帧图像传递给TensorFlow Lite模型进行识别 |

CameraX自动处理设备旋转和镜像问题，且具备生命周期感知能力，无需开发者手动管理相机资源的释放。

### 4.2 ViewModel与LiveData

`RecognitionListViewModel`继承自`ViewModel`类，其核心优势在于**在设备配置变更（如屏幕旋转）时能够保留数据**。识别结果通过LiveData从ViewModel传递给UI层，Activity（或Fragment）作为Observer观察LiveData的数据变化，当识别结果更新时自动刷新RecyclerView。

### 4.3 TensorFlow Lite

TensorFlow Lite包含一个轻量级的运行时环境，专门针对移动端和嵌入式设备进行了性能优化。在本应用中，模型的输入为224×224像素的RGB图像，输出为5个花卉类别的概率分布（概率值范围0~1）。通过排序获取最高概率类别即得识别结果。

## 五、实验中遇到的问题及解决方案

### 5.1 Gradle构建失败与JDK版本不兼容

**问题描述**：初次导入项目时出现“Incompatible Gradle JVM version”错误，Gradle 6.5无法兼容当前使用的JDK 21。

**解决方案**：在 `File → Project Structure → SDK Location` 中将Gradle JDK切换为**JDK 11**。若未安装JDK 11，可通过IDE下载安装后再选择。

### 5.2 TensorFlow Lite依赖版本过旧

**问题描述**：项目原始配置中的TensorFlow Lite依赖版本较旧，可能导致部分依赖无法正常下载。

**解决方案**：在模块的`build.gradle`文件中更新依赖版本为较新版本：

gradle

```
implementation 'org.tensorflow:tensorflow-lite-support:0.3.1'
implementation 'org.tensorflow:tensorflow-lite-metadata:0.3.1'
```



### 5.3 ImageProxy图像旋转问题

**问题描述**：从CameraX获取的`ImageProxy`图像可能存在旋转角度问题，需要根据设备方向进行校正。

**解决方案**：在`toBitmap`扩展函数中获取图像旋转角度，对图像进行相应处理后再转换为Bitmap。

## 七、实验总结

本次实验完成了一个基于TensorFlow Lite的Android花卉识别应用的完整构建流程，包括环境配置、模型集成、核心代码实现和应用测试。

**CameraX相机框架**：熟悉了`Preview`和`ImageAnalysis`两大核心用例的协作模式，以及如何将相机帧数据转换为模型可接受的输入格式；

**Jetpack架构组件**：理解了ViewModel在应对设备配置变更时的数据保留机制，以及LiveData在UI与数据层之间的观察者模式应用。
